# Self-hosted font provenance

Czech Latin Extended subsets added for the public site are copied verbatim from Fontsource 5.3.0 packages and served locally. There is no runtime Google Fonts or CDN dependency.

- `@fontsource/inter@5.3.0` — Inter, upstream font version v4.1, SIL Open Font License 1.1.
- `@fontsource/cormorant-garamond@5.3.0` — Cormorant Garamond, upstream font version v21, SIL Open Font License 1.1.

Added subsets cover the existing application faces only: Inter 400/500/600 normal and Cormorant Garamond 400/500/600 normal plus 400 italic. Existing Latin WOFF2 files remain in place; these additional files supply Latin Extended Czech glyphs.
